# ⚔️ Soulsborne Death Tracker

Небольшой трекер для подсчёта смертей и отслеживания прогресса в марафоне из семи игр Soulsborne.

## 🎮 Игры

1. Demon's Souls
2. Dark Souls Remastered
3. Dark Souls II: Scholar of the First Sin
4. Bloodborne
5. Dark Souls III
6. Sekiro: Shadows Die Twice
7. Elden Ring

## ✨ Возможности

* Подсчёт смертей во время прохождения.
* Глобальные горячие клавиши.
* Переключение между играми.
* Сохранение статистики и дневника прохождения.
* Синхронизация статистики с облаком через Supabase.
* Веб-сайт с актуальной статистикой марафона.

## ⌨️ Управление

| Клавиша | Действие                   |
| ------- | -------------------------- |
| `F8`    | Добавить смерть            |
| `F9`    | Переключить следующую игру |

## 🌐 Веб-сайт

**[Soulsborne Death Tracker](https://muuur133.github.io/soulsborne-tracker.wisp/)**

Статистика отображается на сайте и обновляется из облачной базы данных.

## 🛠️ Технологии

* C++ и Qt 6 — настольное приложение.
* JavaScript, HTML и CSS — веб-сайт.
* Supabase — облачное хранение данных.
* GitHub Pages — публикация сайта.
* CMake — сборка приложения.
